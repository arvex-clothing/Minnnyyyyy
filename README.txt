# A Little Universe For You ✿

A dreamy, cinematic, playful friendship website made with plain HTML, CSS, and JavaScript.

## Open it in VS Code
1. Extract the ZIP file.
2. Open the `dumbo_dreamy_friendship` folder in VS Code.
3. Add your friend's photos to the `images` folder.
4. Open `index.html` using the Live Server extension (right-click → Open with Live Server). You can also double-click `index.html` to open it in a browser.

## Add her pictures
Put your pictures in the `images` folder and name them exactly:
- `her-photo-1.jpg`
- `her-photo-2.jpg`
- `her-photo-3.jpg`
- `her-photo-4.jpg`

If your photos are `.png` or `.webp`, edit the matching image `src` in `index.html` to use the correct extension. You can use only three photos; the fourth frame will show its placeholder.

## Personalize it
Open `script.js` and change:
`const FRIEND_NAME = "Dumboooooooo";`
to her nickname.

Edit the captions in `index.html`, especially the final letter, so it sounds like your friendship.

## New magical features
- Flying fairies and butterflies in an enchanted garden
- A magical carousel/carriage button with randomized messages
- Summon more fairies and make a tiny wish
- Floating sparkle cursor trail, shooting stars, fireflies, and glowing moon
- Extra interactive sparkles and petal animations
- Mobile-friendly layout and reduced-motion support

## Notes
- The animations work without external JavaScript libraries.
- The sound button makes soft synthesized chimes; it does not need an audio file.
- Google Fonts needs an internet connection; fallback fonts are included.
- This is a static website, so it can be hosted on GitHub Pages if you want to share a link.
